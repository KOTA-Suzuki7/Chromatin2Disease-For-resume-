# Source data

This repository uses processed FOF-CT DNA-spot/trace-core tables from the 4D
Nucleome Data Portal. The raw CSV files are downloaded locally and are not
redistributed by this repository.

## Experiment sets

| Condition | 4DN experiment set | Description |
| --- | --- | --- |
| Untreated | [4DNESJ3TXVIR](https://data.4dnucleome.org/experiment-set-replicates/4DNESJ3TXVIR/) | CTCF-AID mouse embryonic stem cells without auxin |
| CTCF-depleted | [4DNES2KX6HQ5](https://data.4dnucleome.org/experiment-set-replicates/4DNES2KX6HQ5/) | CTCF-AID mouse embryonic stem cells after auxin treatment |

## Files used

| Condition | Run group | FOF-CT core accession |
| --- | ---: | --- |
| Untreated | 1 | `4DNFIZWUQTXF` |
| Untreated | 2 | `4DNFIKVZTN9K` |
| Untreated | 3 | `4DNFID7HZ8LX` |
| CTCF-depleted | 1 | `4DNFIJYFR8FT` |
| CTCF-depleted | 2 | `4DNFIIOVHG1I` |
| CTCF-depleted | 3 | `4DNFI4VLY3WU` |

Download the files from the repository root with:

```bash
python scripts/download_data.py
```

The command writes the six files to `data/hafner2023/`. The training pipeline
expects those accession-based filenames.
